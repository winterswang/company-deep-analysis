# 版本变更记录

## V4.2 (2026-03-10)

### 核心改进

| 改进点 | 说明 |
|--------|------|
| **数据来源强制标注** | 所有数据必须标注来源，防止模型幻觉 |
| **文件结构整理** | 合并多个版本为单一框架文件 |
| **行业增速对比** | 新增行业增速对比法 |
| **利润估算模型** | 新增前瞻性分析能力 |
| **统一口径调整** | 借鉴互联网估值表思路 |

### 新增功能

1. **关键指标追踪表**：行业特定的关键指标追踪
2. **行业增速对比**：公司增速 vs 行业增速 → 竞争地位判断
3. **市占率趋势追踪**：连续多年市占率变化 → 护城河判断
4. **利润估算模型**：区分可预测/不可预测因素
5. **统一口径调整**：股权激励、一次性费用处理

### 修复问题

| 问题 | 解决方案 |
|------|----------|
| 任天堂报告幻觉风险 | 强制数据来源标注 |
| 多版本文件混乱 | 合并为单一 SKILL.md |
| V4.1 缺少数据来源要求 | 添加 DATA_STANDARD.md 强制要求 |

### 学习来源

- 宁德时代一张表文章：关键指标追踪、市占率趋势
- 中海油深度分析文章：利润估算模型、可预测性区分
- 互联网估值表文章：统一口径调整、行业横向对比

## V4.1 (2026-03-10)

### 核心改进

引入"否定之否定的辩证分析"方法论

### 六轮辩证推导

1. 第一轮：正题——财务数据初判
2. 第二轮：反题——批判性质疑
3. 第三轮：合题——竞争优势本质
4. 第四轮：再否定——极端情况压力测试
5. 第五轮：估值分析
6. 第六轮：投资决策

## V4.0 (2026-03-10)

### 核心改进

以护城河为核心，财务数据透视竞争优势

### 新增内容

- 护城河趋势分析工具 (`moat_analyzer.py`)
- ROE/毛利率/增速变化分析映射到护城河诊断
- 护城河五要素评估框架
- 护城河趋势判断框架（固若金汤/边际弱化/被侵蚀）

## V3.0 (2026-03-10)

### 核心改进

完善分析框架，添加管理层分析、深度财务分析

### 新增功能

- 管理层分析（核心管理层背景、激励机制、治理结构）
- 深度财务分析（FCF拆解、存货结构、ROIC）
- WACC 测算（必须展示测算过程）
- DDM 估值（分红率>50%公司必用）
- 风险压力测试（情景分析、预警阈值）
- 可操作投资建议（建仓节奏、跟踪指标、退出条件）
