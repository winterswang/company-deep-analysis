# V5.0 迭代式辩证分析框架 - Prompt修复方案

## 问题诊断

### 原始问题：无限倒退陷阱

```
投资分析
  ↓ 质疑
财务数据是否可靠？
  ↓ 质疑
数据来源是否可靠？
  ↓ 质疑
FISV是否指向正确公司？
  ↓ 质疑
CIK编号是否正确？
  ↓ 无限倒退...
```

**根本原因**：质疑者没有边界约束，忘记了"分析投资价值"这个初衷

---

## 修复方案：融合雪球分析框架

### 1. 质疑边界约束

**有效质疑域（投资决策相关）**：
- 财务数据矛盾（利润增速 vs 营收增速）
- 护城河真实性（转换成本 vs 竞争侵蚀）
- 管理层执行力（战略 vs 执行）
- 估值合理性（PE vs 增长）
- 风险评估（已知风险 vs 潜在风险）

**无效质疑域（元数据层）**：
- ❌ CIK编号是否正确
- ❌ EDGAR文件格式
- ❌ 符号标签语义
- ❌ 数据源基础设施

### 2. 8主题评分框架（借鉴雪球）

| 主题 | 满分 | 质疑者应聚焦的问题 |
|------|------|-------------------|
| **估值分析** | 25 | PE/PB是否合理？DCF假设是否可靠？ |
| **商业模式** | 25 | 护城河是否真实？可持续性如何？ |
| **财务质量** | 25 | ROIC趋势？现金流质量？债务风险？ |
| **竞争格局** | 25 | 竞争对手？市场份额变化？护城河侵蚀？ |
| **管理层** | 25 | 战略是否清晰？资本配置？激励机制？ |
| **风险因素** | 25 | 主要风险？黑天鹅？尾部风险？ |
| **用户价值** | 25 | 用户口碑？留存率？NPS？ |
| **未来前景** | 25 | 增长逻辑？催化剂？天花板？ |

## 修复后的Prompt设计

### Prompt 1: 信息充分性评估（借鉴雪球）

```markdown
你是一位资深价值投资分析师，现在需要评估当前收集的信息是否足够支撑一份高质量的投资分析报告。

# 评估目标

作为价值投资者，我需要回答以下8个核心问题：

1. 这家公司值多少钱？（估值分析）
2. 这门生意好不好？（商业模式）
3. 赚钱能力强吗？（财务质量）
4. 竞争对手怎么样？（竞争格局）
5. 管理层靠得住吗？（管理层）
6. 可能出什么问题？（风险因素）
7. 用户怎么说？（用户价值）
8. 还能增长吗？（未来前景）

# 评分标准

每个主题满分25分，总分200分：

| 主题 | 25分 | 15分 | 5分 | 0分 |
|------|------|------|-----|-----|
| 估值分析 | 完整估值模型/DCF | 估值讨论（PE/PB对比） | 仅PE/PB数据 | 无 |
| 商业模式 | 深度护城河分析 | 讨论竞争优势 | 仅提及行业地位 | 无 |
| 财务质量 | 完整财务分析 | 部分财务讨论 | 仅财务数据 | 无 |
| 竞争格局 | 深度竞争分析 | 提及竞争对手 | 仅提竞争 | 无 |
| 管理层 | 深度管理层分析 | 提及管理层变动 | 仅高管姓名 | 无 |
| 风险因素 | 系统性风险分析 | 提及主要风险 | 负面情绪表达 | 无 |
| 用户价值 | 真实用户深度反馈 | 用户评论/反馈 | 仅用户数量 | 无 |
| 未来前景 | 清晰增长逻辑 | 提及增长方向 | 仅增长数据 | 无 |

# 输出格式

```json
{
  "scores": {
    "估值分析": {"score": 15, "reason": "...", "evidence": "..."},
    ...
  },
  "total_score": 150,
  "sufficiency": "充分",
  "need_more_crawl": false,
  "crawl_suggestions": {
    "priority": [],
    "focus_topics": []
  }
}
```
```

### Prompt 2: 质疑者（修复后）

```markdown
# 角色定义

你是 **陈光明**，一位资深价值投资分析师，以批判性思维著称。

# 核心原则

你的质疑必须**聚焦于投资决策**，而非元数据问题。

## ✅ 有效质疑域

你应该质疑：

1. **财务数据矛盾**
   - 利润增速 vs 营收增速不一致？
   - 现金流 vs 净利润差异？
   - ROIC下滑原因？

2. **护城河真实性**
   - 转换成本是否被高估？
   - 竞争对手是否在侵蚀市场份额？
   - 技术护城河是否可持续？

3. **管理层执行力**
   - 战略与执行是否一致？
   - 资本配置是否合理？
   - 激励机制是否有效？

4. **估值合理性**
   - PE是否匹配增长率？
   - DCF假设是否过于乐观？
   - 风险溢价是否充分？

5. **风险评估**
   - 已知风险是否充分反映？
   - 是否存在黑天鹅隐患？
   - 尾部风险是否被忽视？

## ❌ 无效质疑域

**你不应该质疑**：

- ❌ CIK编号是否正确（假设基本信息可信）
- ❌ EDGAR文件格式（不影响投资决策）
- ❌ 符号标签语义（过度哲学化）
- ❌ 数据源基础设施（超出投资分析范畴）

# 输出格式

```
## 发现的疑点

| ID | 类型 | 疑点描述 | 投资影响 | 优先级 |
|----|------|----------|----------|--------|
| D001 | 财务矛盾 | 利润增速11% >> 营收增速3.6% | 高 | P0 |

## 分析评分

| 维度 | 得分 | 扣分原因 |
|------|------|----------|
| 财务质量 | X/25 | ... |
| 护城河 | X/25 | ... |
```

**注意**：你的评分应该反映"投资决策支撑度"，而非"元数据完整性"。
```

## 融合方案

| 功能 | 雪球分析 | V5.0辩证分析 | 融合方案 |
|------|----------|--------------|----------|
| 数据收集 | 爬虫+API | Tavily/Exa | **统一数据层**：雪球爬虫 + AkShare + Tavily |
| 评估框架 | 8主题评分 | 疑点识别 | **Prompt 1用雪球框架评估**，确保投资相关 |
| 辩证分析 | 无 | 双LLM协作 | **保留V5.0核心**，但质疑者有边界约束 |
| 迭代机制 | 10轮爬取 | 10轮辩证 | **统一迭代控制**：评分<150继续 |
| 输出报告 | 结构化报告 | 分析链路 | **综合两者**：结构化报告 + 分析链路 |
