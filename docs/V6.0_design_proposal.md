# Company Deep Analysis V6.0 设计方案

## 基于雪球高质量分析 + 用户收藏文章的重新设计

---

## 一、问题诊断

### 1.1 V5.x 输出问题

| 问题 | V5.x表现 | 雪球分析 |
|------|----------|----------|
| **抽象化** | "不可验证"、"未归因" | 具体业务分析 |
| **疑点类型** | 全是"信息缺失" | 财务讨论、护城河分析 |
| **输出结构** | 疑点列表 | 结构化投资报告 |
| **投资相关性** | 元数据层 | 企业本身 |

### 1.2 高质量分析特征（来自雪球文章）

| 特征 | 示例 |
|------|------|
| **聚焦企业本身** | "携程是流量撮合平台，需要升级为行业共建" |
| **具体财务讨论** | "净利润60%来自投资收益，核心业务增速趋平" |
| **护城河本质** | "高星酒店供应链掌控力是核心护城河" |
| **变化趋势** | "监管压力让携程需要寻找新护城河" |
| **估值分析** | "P/FCF 8倍，EV/FCF 15倍" |
| **投资建议** | "逢低买入，仓位5-8%" |

---

## 二、设计目标

### 2.1 核心目标

**聚焦企业本身**，输出结构化投资分析报告

### 2.2 具体目标

| 目标 | 说明 |
|------|------|
| **业务分析** | 这家公司做什么？商业模式是什么？ |
| **财务质量** | 赚钱能力如何？ROIC/ROE趋势？ |
| **护城河本质** | 核心竞争力是什么？是真护城河吗？ |
| **变化趋势** | 正在发生什么变化？管理层动作？ |
| **估值分析** | 当前估值是否合理？安全边际？ |
| **投资建议** | 买入/观望/避免？仓位建议？ |

---

## 三、架构设计

### 3.1 整体流程

```
┌─────────────────────────────────────────────────────────────┐
│                    V6.0 分析流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   阶段1: 数据收集                                            │
│   ┌─────────────────────────────────────────┐               │
│   │ • 雪球爬虫（专业观点、管理层观点）        │               │
│   │ • AkShare（财务数据、ROIC趋势）         │               │
│   │ • Tavily/Exa（行业分析、竞争格局）       │               │
│   └─────────────────────────────────────────┘               │
│                      ↓                                      │
│   阶段2: 初始化评估（雪球8主题框架）                          │
│   ┌─────────────────────────────────────────┐               │
│   │ • 8主题评分（总分200）                    │               │
│   │ • 充分性判断（>=150进入分析）             │               │
│   │ • 爬取建议                               │               │
│   └─────────────────────────────────────────┘               │
│                      ↓                                      │
│   阶段3: 深度分析                                            │
│   ┌─────────────────────────────────────────┐               │
│   │ Prompt: 资深投资分析师                    │               │
│   │                                          │               │
│   │ 输入:                                    │               │
│   │ - 所有收集的内容                          │               │
│   │ - 财务数据表                              │               │
│   │                                          │               │
│   │ 输出:                                    │               │
│   │ - 执行摘要                               │               │
│   │ - 估值分析                               │               │
│   │ - 商业模式与护城河                        │               │
│   │ - 财务质量                               │               │
│   │ - 竞争格局                               │               │
│   │ - 管理层                                 │               │
│   │ - 投资决策                               │               │
│   └─────────────────────────────────────────┘               │
│                      ↓                                      │
│   阶段4: 辩证验证（可选）                                    │
│   ┌─────────────────────────────────────────┐               │
│   │ 质疑者: 针对分析结论的财务/护城河质疑      │               │
│   │ 解决者: 补充验证                          │               │
│   │ 输出: 最终报告                            │               │
│   └─────────────────────────────────────────┘               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 核心改变

| V5.x | V6.0 |
|------|------|
| 质疑者为主 | **分析师为主** |
| 疑点列表输出 | **结构化报告输出** |
| 双LLM辩证 | **单LLM分析 + 可选辩证** |
| 元数据质疑 | **聚焦企业本身** |

### 4.2 辩证验证 Prompt（可选）

```markdown
# 角色

你是 **陈光明**，睿远基金创始人，以批判性思维著称。

# 任务

针对上述分析报告，提出财务/护城河相关的质疑。

## ✅ 有效质疑域

- 财务数据矛盾（利润增速 vs 营收增速）
- 护城河真实性（定价权证据不足）
- 管理层执行力（战略与执行不匹配）
- 估值合理性（PE与增长不匹配）
- 风险评估（债务风险被低估）

## ❌ 无效质疑域

- CIK编号、EDGAR格式等元数据

# 输出格式

| 疑点 | 分析报告观点 | 质疑 | 建议补充验证 |
|------|--------------|------|--------------|
| [疑点1] | [观点] | [质疑] | [建议] |
```

## 五、输出对比

### V5.x 输出

```
最终假设：
"ROIC回升是共时扰动下的未归因数值峰值..."
```

### V6.0 输出

```
# Fiserv 投资价值分析报告

## 执行摘要

### 估值判断
- 当前估值：**低估**（P/FCF 8倍）
- 核心逻辑：现金流机器 + 新管理层变革

### 投资建议
- 操作方向：逢低买入
- 建议仓位：5-8%

### 核心投资逻辑
1. **极致现金流机器**：近30%营收转现金流
   > 📌 引用："高达15.3亿美元的自由现金流..."
2. **管理层变革**：新CEO来自摩根大通
   > 📌 引用："Takis重组了高管团队..."

## 财务质量分析

| 指标 | 数值 | 趋势 | 解读 |
|------|------|------|------|
| ROIC | 8.74% | ↑ | 接近WACC，处于价值创造临界点 |
| 利息保障倍数 | 1.86 | → | 偏低，容错空间小 |
```
