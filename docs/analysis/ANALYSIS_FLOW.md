## Step 1: 数据收集

### 数据清单

| 数据类型 | 数据项 | 来源 | 优先级 |
|----------|--------|------|--------|
| **财务数据** | 营收、净利润、ROE、毛利率、FCF | AkShare | P1 |
| **行情数据** | PE、PB、市值、换手率 | AkShare | P1 |
| **行业数据** | 行业增速、竞争格局 | 研报/雪球 | P2 |
| **业务数据** | 业务结构、市占率 | 年报 | P0 |

### 数据收集脚本

```python
from scripts.collectors.financial_collector import FinancialCollector
from scripts.collectors.market_collector import MarketCollector

# 收集财务数据
financial = FinancialCollector()
financial_data = financial.collect(code, years=5)
```

### 杜邦分解

```
ROE = 净利率 × 资产周转率 × 权益乘数

分析要点：
- 净利率变化 → 盈利能力变化
- 资产周转率变化 → 运营效率变化
- 权益乘数变化 → 杠杆变化
```

## Step 6: 估值分析

### 估值方法选择流程

```
1. 检查是否适用 DDM
   - 分红率 > 50%？
   - 连续分红 >= 3年？
   - 分红稳定？
   → 是 → 使用 DDM

2. 否则使用 PE/PEG
   - 增速是否稳定？
   - 行业是否有可比公司？

3. 多情景分析
   - 悲观情景
   - 中性情景
   - 乐观情景
```

### 安全边际计算

```
内在价值 = 估值结果
买入价格 = 内在价值 × (1 - 安全边际)

安全边际：
- 高确定性：20-30%
- 中等确定性：30-40%
- 低确定性：40-50%
```
