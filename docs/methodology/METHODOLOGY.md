# 分析方法论

## 辩证分析方法

### 核心理念

**否定之否定**：每个结论都必须被质疑、验证、推翻或确认。分析是螺旋式上升的，不是平铺直叙。

### 三层辩证分析框架

```
┌─────────────────────────────────────────────────────────┐
│                    三层辩证分析框架                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  第一层：财务数据辩证                                      │
│    目的：确认数据真实性                                    │
│    输出：验证后的财务数据                                  │
│                                                         │
│  第二层：护城河本质辩证                                    │
│    目的：识别真护城河 vs 伪护城河                          │
│    输出：护城河类型、强度、边界                             │
│                                                         │
│  第三层：护城河延续性辩证                                  │
│    目的：评估护城河演变趋势                                │
│    输出：延续性评分、预警信号                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 第一层：财务数据辩证

### 目的
确认财务数据的真实性，排除会计处理和一次性因素影响。

### 分析步骤

```
正题：财务数据 → 初步判断
反题：数据是否真实？
  - 是否有会计处理影响？
  - 是否有一次性收益/费用？
  - 是否符合行业规律？
合题：确认财务数据真实性
```

### 关键质疑点

| 财务指标 | 质疑方向 | 验证方法 |
|----------|----------|----------|
| ROE | 杠杆影响？一次性收益？ | 杜邦分解 |
| 毛利率 | 成本下降？提价？ | 对比原材料价格 |
| 增速 | 行业红利？份额提升？ | 对比行业增速 |
| FCF | 资本开支不足？ | 对比折旧摊销 |

## 第二层：护城河本质辩证

### 目的
识别护城河的真实性，区分"真护城河"和"伪护城河"。

### 分析步骤

```
正题：从财务数据推断护城河
反题：护城河是否真实？
  - 是护城河还是行业红利？
  - 是能力还是运气？
  - 是可持续优势还是一次性机会？
合题：护城河本质验证
再否定：护城河边界条件
```

### 护城河类型识别

| 财务特征 | 可能的护城河类型 | 典型行业 |
|----------|------------------|----------|
| 高ROE + 高毛利率 | 品牌溢价 | 消费品 |
| 高ROE + 低毛利率 + 高周转 | 成本优势 | 零售 |
| 高ROE + 高研发投入 | 技术壁垒 | 医药 |
| 高ROE + 用户增长 | 网络效应 | 平台 |

### 真实性评分

| 等级 | 说明 | 特征 |
|------|------|------|
| A级 | 真护城河 | 跨周期验证，竞争对手无法复制 |
| B级 | 较强护城河 | 基本验证，竞争对手追赶困难 |
| C级 | 弱护城河 | 验证不足，竞争对手正在追赶 |
| D级 | 伪护城河 | 主要是行业红利，容易复制 |

## 第三层：护城河延续性辩证

### 目的
评估护城河的演变趋势，识别侵蚀因素和强化因素。

### 分析步骤

```
正题：护城河当前状态
反题：护城河正在被侵蚀吗？
  - 技术变革？
  - 竞争加剧？
  - 消费习惯变化？
合题：护城河演变趋势
再否定：护城河失效临界点
```

### 侵蚀因素框架

| 侵蚀因素 | 具体表现 | 影响程度 |
|----------|----------|----------|
| 技术变革 | 新技术颠覆传统模式 | 高/中/低 |
| 竞争加剧 | 竞争对手追赶、新进入者 | 高/中/低 |
| 消费习惯 | 消费者偏好改变 | 高/中/低 |
| 监管政策 | 政策变化影响商业模式 | 高/中/低 |

### 预警等级

| 等级 | 说明 | 投资建议 |
|------|------|----------|
| 🔴 红色 | 护城河即将失效 | 避免投资 |
| 🟠 橙色 | 护城河加速侵蚀 | 暂缓投资 |
| 🟡 黄色 | 护城河出现侵蚀迹象 | 谨慎投资 |
| 🟢 绿色 | 护城河稳定或加强 | 可正常投资 |

## 估值方法论

### 估值方法选择

| 条件 | 推荐方法 | 质疑点 |
|------|----------|--------|
| 分红稳定且分红率高 | DDM | 分红是否可持续？ |
| 增速稳定可预测 | DCF | 增速假设是否过于乐观？ |
| 行业周期性强 | PB | 资产质量如何？ |
| 高成长 | PE/PEG | 增速是否能维持？ |

### DDM 估值适用条件

```
必须同时满足：
1. 分红率 > 50%
2. 连续分红 >= 3年
3. 分红稳定性（波动 < 20%）
```

### 安全边际原则

```
买入价格 = 内在价值 × (1 - 安全边际)

安全边际设置：
- 高确定性公司：20-30%
- 中等确定性：30-40%
- 低确定性：40-50%
```

## 数据质量管理

### 数据源分级

| 级别 | 来源类型 | 使用规则 |
|------|----------|----------|
| P0 | 官方年报/IR | 直接使用 |
| P1 | TuShare/AkShare | 直接使用 |
| P2 | 雪球/研报 | 交叉验证后使用 |
| P3 | 专业自媒体 | 标注偏见风险 |
| P4 | 普通来源 | 仅作参考 |

### 置信度标注

| 置信度 | 说明 | 使用方式 |
|--------|------|----------|
| verified | 已验证，来自 P0/P1 | 直接使用 |
| estimated | 估算，需标注依据 | 谨慎使用 |
| model_hallucination | 模型幻觉 | **禁止使用** |
