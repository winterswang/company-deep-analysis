## 第二轮：反题——批判性质疑

### 2.1 行业增速对比（V4.2 新增）

**核心问题**：公司增速是否跑赢行业？

| 指标 | 迈瑞增速 | 行业增速 | 差异 | 竞争地位判断 |
|------|----------|----------|------|--------------|
| **营收增速** | 5.14% | 3-5%（医疗器械） | +0-2% | ✓ 略超行业 |
| **海外增速** | ~10% | 5-8%（中国出海） | +2-5% | ✓ 跑赢行业 |
| **国内增速** | ~3% | 2-4%（医疗新基建退坡） | +0-1% | ≈ 与行业持平 |

**反题结论**：
```
公司增速略超行业增速 → 市占率微增 → 竞争优势稳定

但需警惕：
- 国内增速接近行业均值，可能是行业整体下行
- 海外增速跑赢，说明国际化战略有效
```

### 2.2 财务变化深层质疑

**质疑一：ROE 下降是竞争恶化还是投资节奏？**

**杜邦分解验证**：

| 因素 | 2023 | 2024 | 贡献度 | 判断 |
|------|------|------|--------|------|
| 净利率 | 33.16% | 31.77% | -1.5% | 盈利能力下降 |
| 周转率 | 0.73 | 0.65 | **-3.8%** | **主因** |
| 杠杆 | 1.44 | 1.39 | -1.1% | 去杠杆 |

**发现**：资产周转率下降是主因（-3.8%），说明资产扩张快于销售增长。

**质疑二：毛利率下降是定价权丧失还是产品结构调整？**

**业务线拆解**：

| 业务线 | 2024毛利率 | 增速 | 判断 |
|--------|-----------|------|------|
| 体外诊断 | 65.5% | +10.2% | 高毛利且增长 |
| 生命信息 | 62.0% | +5.3% | 稳定 |
| 医学影像 | 60.0% | **-2.0%** | 拖累整体 |

**发现**：医学影像业务下滑拖累整体毛利率，非定价权丧失。

## 第四轮：前瞻性分析（V4.2 重大改进）

### 4.1 利润估算模型（借鉴中海油思路）

**商业模式简洁表达**：

```
利润 = 营收 × 净利率

其中：
营收 = (国内收入 + 海外收入)
     = 国内医疗器械市场 × 市占率 + 海外市场 × 海外份额

净利率 = 毛利率 - 费用率 - 税率
```

### 4.2 关键假设与追踪

| 因素 | 2024实际 | 2025假设 | 2026假设 | 可预测性 | 来源 |
|------|----------|----------|----------|----------|------|
| **国内医疗器械增速** | 3-5% | 4% | 5% | ✓ 可预测 | 行业报告 |
| **迈瑞市占率** | 5.5% | 5.7% | 5.9% | ✓ 可预测 | 历史趋势 |
| **海外收入增速** | 10% | 12% | 15% | ✓ 可预测 | 公司指引 |
| **毛利率** | 63.1% | 63% | 63% | ≈ 假设稳定 | 历史稳定 |
| **费用率** | 28% | 28% | 28% | ≈ 假设稳定 | 历史稳定 |

### 4.3 利润预测

**2025年利润估算**：

```
国内收入 = 367亿 × 48% × (1 + 4%) = 183亿
海外收入 = 367亿 × 42% × (1 + 12%) = 173亿
其他收入 = 367亿 × 10% = 37亿

总营收 ≈ 393亿（+7%）

净利润 = 393亿 × 30% = 118亿
调整后净利润 ≈ 123亿
```

**2026年利润估算**：

```
总营收 ≈ 425亿（+8%）
净利润 ≈ 128亿
调整后净利润 ≈ 133亿
```

### 4.4 可预测 vs 不可预测因素

| 因素 | 可预测性 | 处理方式 |
|------|----------|----------|
| **公司市占率** | ✓ 可预测 | 假设微增（历史稳定） |
| **公司成本** | ✓ 可预测 | 假设稳定 |
| **海外拓展** | ✓ 可预测 | 公司指引 |
| **国内医疗政策** | ✗ 不可预测 | 多情景分析 |
| **集采范围** | ✗ 不可预测 | 找锚点（已大部分覆盖） |

**不可预测因素处理**：

```
锚点1：集采已覆盖大部分产品，未来边际影响递减
锚点2：医疗新基建已退坡，政策风险边际降低

多情景分析：
- 悲观：政策继续收紧，增速 0-2%
- 中性：政策稳定，增速 5-7%
- 乐观：政策放松，增速 8-10%
```
